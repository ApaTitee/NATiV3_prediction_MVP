## 5. 机制论证（详见 `report/mechanism.md`）

pan-PPAR α/δ/γ 平衡激动覆盖 MASH 三大病理轴（代谢/炎症/纤维化），生物标志物证据链完整（脂联素 ↑4.5×、HbA1c↓、Pro-C3、ALT）；"部分 γ 激动"设计以牺牲部分疗效换取耐受性——这与 Ph2b 中 800mg 未达主终点、胜负手集中于 1200mg 的剂量-效应结构一致。

## 6. 证据层（任务评分点 7：支持/反对分列）

**支持证据**（论点 — 引文 — 等级 — 入模路径）：
1. Ph2b 复合终点效应量大且两个口径一致：NEJM（SAF 口径）复合 35%/25% vs 9% [C11, A]；公司 deck（CRN-like，F2/F3）33%/24% vs 7%，效应量 24–26pp [C09, B] → 先验锚 Δ_ph2=26pp；
2. 类内正例证明该终点结构可达：resmetirom 52 周双终点均显著 [C13, A]；semaglutide 72 周复合 32.7% vs 16.1%（Δ16.5pp）[C14, A]；
3. 设计执行有利：超募（1009 vs 969）、W72 前脱落 <30% 有融资条款佐证 [C05, B]；72 周疗程长于 NATIVE 的 24 周，利于纤维化改善；
4. F2/F3 与 T2D 富集：Ph2b 亚组中复合效应量在 F2/F3 反而升高至 26pp [C09, B]；
5. 安慰剂率有天花板：非肝硬化 MASH 缓解安慰剂汇总 11%（8–14%）[C15, A]，复合终点安慰剂率必然更低（先验中位 ≈7%）。

**反对证据**：
1. Ph2→Ph3 效应衰减是行业常态（中心读片更严、人群更广、执行噪声）→ 以贴现参数 a0（基线 0.5，网格 0.3–0.7）入模；
2. 类内失败先例：elafibranor（PPAR α/δ）RESOLVE-IT Ph3 未达主终点 [C16, C 级，无同行评议主结果文] → 机制失败情景 S4（权重 10%）；
3. GLP-1 drop-in 允许（随机化后可启用）[C08, B] → 安慰剂臂上行 **+1.5pp（分析者假设**，冻结于 analysis_plan.md §3，敏感性 0–3pp；红队压力角 +5pp 见 §8）；
4. 800mg 在 Ph2b 未达主终点（48% vs 33%, p=0.07）[C10, A] → 若 SAP 要求两剂量同时显著，P 降至 0.567；
5. 测量噪声：活检采样误差与读者间变异 → 已含于 a0 贴现与 ρ 网格。

## 7. 定量模型（任务评分点 5：概率是算出来的）

**方法**：混合先验 assurance + 整试验 Monte Carlo 模拟器（`src/model/`，M=200,000，seed=42）。
- **复合终点分项联合建模**：π = q_R·q_F + ρ·√(q_R(1-q_R)q_F(1-q_F))；安慰剂 q_R~Beta(0.11, κ=80) [C15]、q_F~Beta(0.14, κ=60) [C13]、ρ=0.5±0.12 → π_pbo 先验中位 ≈7%（与 NATIVE deck 的 7% 独立吻合）；
- **效应量贴现**：Δ_1200 ~ TN(0.26·a0, 0.05²)，a0 基线 0.5（S1 0.65 / S2 0.50 / S3 0.30 / S4 0.05，权重 0.20/0.45/0.25/0.10 冻结于 analysis_plan.md §4）；Δ_800 = 0.63·Δ_1200 [C11]；
- **脱落/NRI**：d~Beta(0.275, κ=40) [C05]，观测率 π_obs = π·(1−d)；
- **模拟器**：每次抽样生成三臂二项数据 → 共享安慰剂的两比例 z 检验 → Hochberg/备选规则裁决 → 成败指示。共享对照相关性由模拟天然处理；
- **LLM 角色声明**：数值先验完全由 `src/model/priors.py` 从 `evidence.csv` 经显式公式生成；**未使用任何 LLM 自述置信度作为概率输入**（LLM 仅用于证据结构化/红队/审校，见 §11）。

**结果**（全部数值可回溯：`artifacts/model/verdict.json`、`assumption_matrix.csv`、`scenario_table.csv`、`prior_robustness_grid.csv`、`design_implied_delta.csv`）：
| 指标 | 值 | 出处 artifact |
|---|---|---|
| **P(success) 基线** | **0.753 ± 0.001 (MCSE)** | `verdict.json:P_base` |
| 假设矩阵范围 | 0.567（两剂量须同时显著）– 0.780（MI） | `assumption_matrix.csv` |
| 先验网格范围（a0×ρ） | 0.544（a0=0.3,ρ=0.7）– 0.908（a0=0.7,ρ=0.3） | `prior_robustness_grid.csv` |
| 情景分解 | S1 0.959×0.20 + S2 0.867×0.45 + S3 0.581×0.25 + S4 0.256×0.10 | `scenario_table.csv` |
| 观测率（NRI 后，基线） | pbo 6.4% / 800mg 11.7% / 1200mg 14.8% | `verdict.json:pi_obs_mean_base` |
| 设计反演 | p0=7%、脱落 30% 时 90% power 需真实 Δ≈11.5pp；先验 Δ 中位 11.7pp | `design_implied_delta.csv` |

**判定（冻结规则：P_base≥0.50 且 I80 下界≥0.35）**：0.753 ≥ 0.50 且 0.57 ≥ 0.35 → **positive**。

## 8. 不确定性（任务评分点 8：三层分述）

1. **参数不确定性**：先验宽度已积分入 P；单因素敏感性（tornado）显示最大摆幅来自脱落率（0.72–0.77）与 ρ（0.73–0.78）——结论对这些均不敏感；
2. **结构不确定性**：假设矩阵全格 P ∈ [0.567, 0.780]；即使最不利格（两剂量须同时显著）仍 >0.5；先验超参最差角（a0=0.3, ρ=0.7）P=0.544；
3. **模型不确定性**：①终点 crosswalk（SAF→CRN 口径差）由 a0 一次性吸收，是最脆弱一环；②S4（机制失败）的 10% 权重是主观判断，敏感性见 scenario 图；③I80=[0.57,0.89] 为稳健性区间（矩阵×网格单元分布的 10–90 分位），**非**贝叶斯可信区间；
4. **不可建模的不确定性**：SAP 原文未公开；若真实 SAP 采用"两剂量同时显著 + 可评估人群"等极端组合，P 可能低于矩阵覆盖范围。

**R3 红队压力测试（事后增补，不改冻结先验与基线）**：针对红队三个高强度质疑计算的极端角——
| 压力角 | 设置 | P |
|---|---|---|
| 联合高安慰剂 | q_R=0.16, q_F=0.20, ρ=0.6 → π_pbo≈14%（对齐 ESSENCE 安慰剂水平） | 0.701 |
| 差异性 GLP-1 启用 | 安慰剂臂 +5pp（远超 ~10% 渗透的线性预期，模拟"安慰剂臂因无效更多启用"） | 0.720 |
| 两角叠加 | 上两者同时成立 | **0.678** |
→ 即使在红队构造的最不利叠加角下 P 仍 ≥0.65，判定结论稳健。

**红队质疑处置表**（完整输出见 `artifacts/llm/20261008T072253Z_r3_parsed.json`）：
| 质疑 | 处置 |
|---|---|
| SAF vs CRN 终点口径错配（高） | 已知的 crosswalk 最脆环；公司 deck 的 CRN-like 口径（7%→33%，Δ=26pp）与 NEJM SAF 口径（9%→35%，Δ=26pp）在效应量上独立一致，a0 贴现吸收残余差异；§8.3 已声明 |
| 安慰剂复合率 6.4% 远低于 ESSENCE 16.1%（高） | 见上压力角（π_pbo≈14% 时 P=0.701）；ESSENCE 安慰剂率高企部分归因于 GLP-1 试验人群的大幅减重背景（安慰剂 −2.0% 体重），NATiV3 要求体重稳定入组（C04），取低端有依据 |
| NRI vs MI 摆幅仅 2.7pp 疑似过小（高） | 数值核查：中位 Δ 处 power(NRI)=0.985 vs power(MI)=0.995——因设计在 90% power 点 overpowered，衰减后仍处饱和区，摆幅小是正确行为而非实现错误 |
| 探索队列可能被并入主分析 | PR 明确主分析人群为主队列（C05/C06），并入可能性极低，列为残余风险 |
| 复合+次要终点跨终点 Hochberg | 若 SAP 跨终点分配 α，复合终点 α 可能更低；α=0.025 格（P=0.710）部分覆盖该情形 |

## 9. 局限

- 公司口径（90% power、24–26pp 效应量）为 B 级自利来源，已做贴现与敏感性处理，但无法排除口径包装；
- "达终点 ≠ 可批准"：安全性（体重增加/水肿/贫血）与监管裁量不在本预测范围（C18 仅注脚）；
- N=664 盲态合并分析未核到原始出处，未入模（若真实且与先验冲突，将是重要的更新信息）；
- 安慰剂率的历史变异大（ESSENCE 安慰剂缓解率 34.3% vs meta 11%），本模型以体重稳定入组标准为理由取了低端——若 NATiV3 安慰剂复合率漂向 12%+，P 将下移约 5–10pp（见 tornado q_R/q_F）。
